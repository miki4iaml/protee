**Protée : recherche opérationnelle et résolution adaptative des
graphes de profil de vie.**

Pur Python ; il fonctionne sur un poste hors ligne (aucun solveur,
service ou moteur en ligne).

> Projet à ses tout débuts (pré-alpha) : son modèle et ses solveurs sont
> en cours de conception.

## Installation

Le paquet n'est pas encore publié. Depuis un clone du dépôt, avec
[uv](https://docs.astral.sh/uv/) et Python 3.14 ou plus récent :

```
uv sync
```
